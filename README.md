# 異星防線

第一人稱 3D 生存射擊網頁原型。移動、瞄準並擊退三波原創異星生物。

## 操作方式

- **WASD**：移動
- **滑鼠**：瞄準
- **滑鼠左鍵**：射擊
- **R**：重新裝填
- **Esc**：暫停；按「繼續遊戲」恢復

## 執行

用最新版 Chrome 或 Edge 開啟 `index.html`。遊戲使用 CDN 載入 Three.js，因此首次開啟時需要網路連線。

## 功能

- 3D 廢棄隔離區場景與第一人稱滑鼠視角
- 三波逐漸加強的異星生物攻勢
- 生命值、彈藥、分數、重新裝填與勝敗流程
- 命中、受傷與射擊回饋
